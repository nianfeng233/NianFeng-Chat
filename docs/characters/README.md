# 角色卡与双 bot 联动配置（哥伦比娅 / 桑多涅 / 小风）

本目录包含三份可直接粘贴到「新建角色 → 人格设定 / 编辑角色 → 人格设定」的扮演提示词：

- `哥伦比娅.md`
- `桑多涅.md`
- `小风.md`

哥伦比娅与桑多涅这两张卡已经按官方语音、游戏剧情、BWIKI / 萌娘百科和玩家社区共识重写过，重点修正了「把哥伦比娅写成病娇谜语人」「把桑多涅写成普通高冷御姐 / 巨大傀儡」这类常见 OOC。
改写依据与来源见 `研究笔记.md`。两份角色卡都已加入群聊互动与“不替对方行动”的规则；哥伦比娅这张还额外写了点歌台 / 语音条的功能提示词。
两份提示词都适配了念风的人设注入、群聊发言者标签和 QQ 官方机器人渠道，并额外写了双执行官互动的规则。

`小风.md` 是念风本人使用的专属角色卡，不与双 bot 联动绑定。它按当前项目的工具协议写成：短聊天通过 `chat_send` 分条发送，长资料交给 `send_document`，记忆召回走 `search_memory`，联网交给 `web_search` / `browser`，并覆盖 `kb_*`、`media_*`、`agnes_*`、`napcat_*` 等可选插件的使用分寸。对应插件未安装时，这些工具不会出现在 system 的工具清单里，角色不会凭空调用。

## 一、框架侧准备

1. 在「会话」里分别创建两个角色：`哥伦比娅`、`桑多涅`。
2. 把 `哥伦比娅.md` / `桑多涅.md` 的正文分别粘贴进对应角色的人格设定。
3. 在「渠道 → 添加渠道 → QQ官方机器人」里创建两个渠道：
   - 渠道分类选 **群聊**；
   - 渠道名称建议就填 `哥伦比娅` / `桑多涅`，联动镜像用这个名称标注发言者；
   - 分别绑定两个官方 bot 的 AppID / AppSecret，并接入。
4. 把两个官方 bot 都拉进同一个 QQ 群。
5. 分别在两个渠道里点「接入」，让两个群各自完成一次 `GROUP_AT_MESSAGE_CREATE`（在群里 @ 对应 bot 一次即可），自动绑定或手动绑定 `group_openid`。
6. 如果想让哥伦比娅通过点歌台唱《新月的摇篮曲》一类的歌、发 QQ 语音条：安装 `media-post`（点歌台）与 `web-access`，并在「设置 → 点歌台」一键安装 ffmpeg；QQ 官方机器人渠道会自动把音频转成 SILK 语音发出。

### 小风专属角色（可选）

1. 新建角色 `小风`，把 `小风.md` 正文粘进人格设定；
2. 想让她联网、记事、点歌、处理群管，再按需安装 `web-access`、`knowledge-base`、`media-post`、`agnes-media`、`napcat-group-guard` 等插件；
3. 未安装的工具不会进入 system 工具清单，角色不会硬调，也不该因此报错。

## 二、开启双 bot 联动

QQ 官方接口只把「@机器人」的消息推送给被 @ 的那个 bot。也就是说，A 的回复默认不会出现在 B 的模型上下文里。
为了补上这一点，QQ 官方机器人渠道增加了本地联动：

1. 分别打开两个群聊渠道的「编辑渠道 → 群聊规则」；
2. 在「跨机器人联动标识」里填 **同一个值**，例如：
   - 两个渠道都填 `fatui-harbingers`；
3. 按需设置「自动接话轮数上限」：
   - `1`：每个用户消息后，两位最多各接一轮，推荐；
   - `0`：只同步上下文，不自动接话；
   - 最大 `5`，越高越容易变成两人自说自话，也更耗模型额度；
4. 「对方机器人发言时自动接话」保持勾选即可开启自动接话；关闭后，对方的消息仍会写入自己的群上下文。

原理：

- A 回复群消息后，A 的 bridge 会把这条出站消息镜像写入填了同一个联动标识的 B 渠道；
- B 的前端把它当成一条群聊消息写入 B 的上下文，来源显示为 A 的渠道名；
- 如果 B 开启了自动接话且轮数未到上限，B 会回应 A；
- B 的回应又会镜像回 A，形成一轮可控的联动，而不是无限互刷。

## 三、使用方式

- 在群里 @ 其中任意一位，她回复后另一位会按上限自动接话一轮；
- 如果你关闭了自动接话，可以等另一位被 @ 时，她会读到对方之前说的话并自然接上；
- 想让她们聊得久一点，把两个渠道的「自动接话轮数上限」都设为 `1`，一次 @ 就能看到一轮来回；
- 想临时只让其中一位说话，把对应渠道的「对方机器人发言时自动接话」暂时关掉即可。

## 四、注意事项

- 联动镜像只在本机同一个念风实例内生效；两个渠道需要在同一个客户端里配置。
- 镜像消息不会调用 QQ 接口，只在本地写入上下文 / 触发模型；实际群聊里看到的仍是两位 bot 各自发到群里的消息。
- 自动接话会消耗模型额度，建议轮数上限保持 `1`。
- QQ 官方 bot 看不到群里没有 @ 自己的普通消息；这是官方协议限制，不是插件问题。

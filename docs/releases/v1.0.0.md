# 念风 Chat v1.0.0

首个 1.0 正式版本。

## 渠道

- 新增 **NapCat** 渠道插件（OneBot 11）：
  - 私聊 / 群聊 / 隐私三类渠道；
  - 目标 QQ 号 / 群号；
  - 同一 NapCat 登录 QQ 可被多个渠道复用，不需要重复创建连接；
  - Forward WebSocket 与 Reverse WebSocket 两种连接模式；
  - Reverse 支持反向主机 / 端口 / 路径（默认 `/ws`）配置，Token 可选；
  - 群聊规则：黑名单、白名单、仅艾特回复、回复概率、引用回复、艾特触发者、静默写入上下文；
  - 群聊上下文固定为本群最近 20 轮；
  - 发现会话、连接状态管理与通用 OneBot action 透传。
- 继续内置微信clawbot、QQ官方机器人渠道。
- 渠道插件可以声明必须依赖与可选依赖：
  - 缺失必须依赖：插件标红并阻止加载；
  - 缺失可选依赖：插件标黄但继续运行。

## 聊天记录存储

- 聊天原文从单个 `sessions.json` 迁移到内置 SQLite `chat.db`；
- `sessions.json` 仅保留会话元数据，避免聊天记录增长后反复重写大 JSON；
- 旧数据首次启动自动迁移，原文件保留为 `sessions.json.full.bak`；
- 前端继续使用原有会话 / 气泡展示模式，消息写回改为消息级 API；
- `localStorage` 仅保留最近 20 条做离线兜底，完整历史以数据库为准。

## 桌面端 / Web 端

- 桌面版在没有 WebView2 Runtime 时：
  - 优先从国内加速镜像下载安装器并静默安装；
  - 安装失败自动回退到默认浏览器打开 WebUI，Node 服务继续后台运行；
  - 支持 `NIANFENG_WEBVIEW2_INSTALLER_URL`、`NIANFENG_WEBVIEW2_INSTALLER_PATH` 等配置。
- Web 部署版新增「启动念风-无浏览器.cmd」，适合云服务器，不依赖 WebView2。
- 关闭旧后端连接、reverse WebSocket 时做资源清理，避免关闭卡住。

## 其他

- NapCat 渠道回复概率支持滑块 + 数字输入框精调；
- 渠道列表在新建 / 移动到其他分类后会自动切换到对应 Tab；
- 渠道详情发现会话支持「新建渠道」和「设为本渠道目标」两种操作。

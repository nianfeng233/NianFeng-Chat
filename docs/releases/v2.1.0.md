# 念风Chat v2.1.0

本次稳定版包含访问令牌加固、备用模型列表和一批启动 / 发布可靠性优化。

## 新增

- **备用模型改为有序列表**：设置 → 模型里可以自由添加、移除、上下移动或拖拽调整备用模型顺序；当前模型在输出任何内容前失败时，会按列表顺序逐个尝试。
- **备用列表循环轮数**：可设置整份列表失败后从头再循环 1～3 轮。
- **访问令牌引导**：有终端的部署首次启动时，会在终端最上方打印随机访问令牌；已有安装如果开放监听但从未设置令牌，也会自动补一个令牌并提示复制。
- **访问令牌再次修改**：设置页支持覆盖或清除访问令牌；保存后只写入盐化摘要，不保存明文，也不会回显旧令牌。

## 安全

- 开放监听默认要求访问令牌；`NODE_ENV=production` 且监听 `0.0.0.0` / `::` 时，没有令牌会直接拒绝启动。
- 旧版 `network.webuiToken` 明文在启动时自动迁移为摘要，迁移后删除明文字段；不再写入 `.webui-token` 明文文件。
- 访问令牌最少 12 位，由后端强制校验。
- Cookie 在 HTTPS / 反向代理场景下自动加 `Secure`；Host / Origin / CORS / 静态目录边界继续按白名单严格校验。
- WebUI 代理与后端 HTTP 插件共用同一套令牌、Cookie、Host / Origin 和 401 页面逻辑。

## 优化

- 访问令牌校验不再每个请求克隆整份配置。
- 备用模型拖拽后只刷新列表区块，不再整页重绘。
- 新增代码风格检查、发布版本同步检查和更完整的发布前静态校验。
- 桌面版不再读取或写入 `.webui-token`；需要令牌且浏览器没有 Cookie 时，会显示令牌输入页。

## 升级说明

- 旧版 `model.failoverRetries` 会自动迁移为 `model.failoverPasses`。
- 旧版明文访问令牌会自动迁移；非本机监听且从未设置令牌的实例，升级后的首次启动会在终端打印随机令牌，请复制保存。
- 已经设置过访问令牌的实例不会重新打印明文；忘记令牌时，可用环境变量 `NIANFENG_WEBUI_TOKEN` 临时启动，再在「设置 → 网络」里重设。
- 桌面版本地默认仍只监听 `127.0.0.1`；如需开放到局域网 / 公网，请先在设置中配置访问令牌。

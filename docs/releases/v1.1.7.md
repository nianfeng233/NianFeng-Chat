# 念风 Chat v1.1.7

本版本包含独立运行日志视图、插件依赖标注系统，以及日志页的稳定性修复。

## 新功能

### 独立运行日志视图

- 运行日志从 `settings-container` 页面改为 `view-router` 的 `logs` 视图。
- 侧栏日志按钮直接 `view-router.switch('logs')`，并先关闭可能打开的设置浮层。
- 新增全宽视图能力：日志激活时隐藏左侧会话 / 渠道列表与拖拽条，日志主面板独占右侧区域。
- 新增懒挂载能力：日志视图第一次点开时才建立日志采集、SSE 与轮询，不在 app 启动时常驻后台。
- 设置导航中不再出现「运行日志」，设置页内也不再有日志路由。
- 日志页面自带独立标题、工具栏与滚动容器，视觉上不再依赖设置页内容区。
- 日志列表按时间排序，SSE、轮询与历史回填混排后顺序稳定。
- 后端日志实例变化时自动全量重同步；请求响应不完整时会根据 `total` 自检再次补齐。

### 插件依赖标注系统

- 93 个内置前端插件全部显式声明 `depends`（必须依赖）与 `optionalDepends`（可选依赖）。
- 当前共 310 条必须依赖，22 个插件声明可选依赖。
- 版本范围支持 `*`（任意）、`>=`（大于等于）、`=`（精确锁定）、`^` / `~`（兼容范围）、`1.x` 与连字符范围等写法。
- 必须依赖缺失、被禁用、加载失败或未激活时标红并阻止插件激活；可选依赖异常只标黄，不影响基础功能。
- 插件列表与详情展示每条依赖的目标、范围、实际版本和原因；`npm run sync-plugins` 与 `npm run test:deps` 负责校验。

### 日志同步修复

- 修复 `after` 增量分页跳游标的问题：浏览器休眠 / 断线期间积压超过一页时，不再永久漏掉中间日志。
- 修复历史回填、SSE 与轮询日志的插入顺序问题：前端统一按时间排序后再渲染。
- 修复「刷新」按钮清空列表后重建的问题：刷新改为合并式重同步，避免后端响应不完整时反而退回旧日志。
- 增加后端 `total` 自检：首次全量拉取不完整时自动强制重拉一次。

# 念风Chat v2.2.1-preview.3

本版延续 v2.2.1 的预览线，主要修复 Gemini 提供商获取模型列表的问题，并补充角色卡文档。

## 模型与代理

- 修复 Gemini 模型列表请求在收到 `HTTP 200` 响应头后卡住的问题：响应体改由同一条流读取，
  避免与流式读取抢占导致 body 永远读不完。
- 模型列表请求显式携带 `pageSize` 并跟随 `nextPageToken` 分页，兼容只声明
  `streamGenerateContent` 或缺少 `supportedGenerationMethods` 的模型。
- 优化 HTTP 代理隧道：CONNECT 请求头与 curl 对齐；CONNECT、TLS 握手、响应体读取全阶段都带超时，
  异常时返回明确错误，不再无限“获取中”。
- 新增代理分阶段日志，便于定位 CONNECT / TLS / 响应体卡在哪一步。

## 文档

- 新增 `docs/characters/小风.md` 专属角色卡，并在 `docs/characters/README.md` 中补充使用说明。

## 其他

- 更新版本号到 `2.2.1-preview.3`。

# 念风 Chat v1.1.4

本版本跟进修复严格工具模式纠错、日志页刷新体验、空批量工具条和角色级渠道权限不同步问题。

## 修复与改进

### 严格工具模式纠错

- 模型直出正文被驳回后，不再只发一句“你没有调用工具”。
- 纠错消息现在明确携带：
  - 上一轮回复已被系统驳回；
  - 驳回原因是未调用工具，普通 assistant 正文不会被投递给用户；
  - 被驳回正文原文与驳回时间，供模型理解后重新组织；
  - 必须调用工具（优先 `chat_send`）并 `end=true` 的重新处理要求。
- system 规则补充协议说明：只有历史里的 `assistant.tool_calls` 才是真正调用过的工具，`role=tool` 是工具返回；没有 `tool_calls` 的普通 assistant 正文不代表本轮应继续输出 assistant。

### 日志页

- 默认级别改为「信息及以上」，需要逐帧细节时再手动切「全部（含调试）」。
- 新增「刷新」按钮：SSE / 反代缓冲 / 旧后端导致列表没跟上的，点击后立即强制重新拉取后端全量日志。
- 切回日志页或窗口重新聚焦时立即补拉一次，避免后台标签页节流后看起来“没刷新”。
- SSE 首包增加 `flushHeaders()` / `setNoDelay()`，降低 Windows 云服务器或反向代理缓冲导致实时性差。
- 状态栏会说明当前是实时流、轮询兜底还是旧后端；旧进程缺少 runtime 能力时给出重启提示。
- 侧栏新增运行日志入口，并固定在设置按钮正上方，排查日志不用先进设置页。

### 消息列表

- 全局补充 `[hidden]{display:none !important}`，修复 `.batch-bar` 自带 `display:flex` 覆盖 `hidden` 后，未进入批量模式也显示“已选 0 / 全选 / 导出 / 删除”的问题。
- 同类修复顺带覆盖手机端返回键、输入区附件栏、渠道弹窗中被 `display` 覆盖的 `hidden` 元素。

### 渠道权限同步（角色级）

- 渠道详情里的“跨渠道读取 / 发送 / 敏感确认”与设置 → 渠道授权、`chat-permissions` 校验统一为**角色级策略**。
- 新增 `channel:permissions-changed` 事件：渠道详情保存权限后，自动同步到该角色下的网页 / 微信 / QQ 等全部渠道会话与渠道配置。
- 新增 `chat-permissions.setRolePolicy()`：设置页开关会回写所有同角色渠道的 `channel.meta.permissions` 与会话 meta。
- `chat-permissions.contextFor` 使用角色聚合策略，避免“渠道详情全开、设置页 / 实际校验却按单个渠道关闭”的矛盾。
- 新增渠道不再用默认关闭值误关角色已有策略，而是继承当前角色策略。
- 更新权限不会改变会话 `updatedAt`，避免角色下所有渠道在会话列表里被反复顶到前面。

### 同义设置项全量检查

- 全局「随机性 temperature」与模型列表里的单模型 temperature 原本存在冲突：chat-flow 始终传全局值，导致模型级 temperature 永远不生效。现在 chat-flow 标记 `preferModelParams`，有单独配置的模型优先使用模型级参数，未配置时回退全局默认值；全局帮助文案也明确说明。
- 继续保留“全局敏感确认 → 角色级渠道 confirm”与“全局工作记忆轮数 → 渠道 contextRounds 覆盖”这类有明确优先级的分层设置。

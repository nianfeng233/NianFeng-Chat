# 念风Chat v2.2.1-preview.8

本版修复模型失败降级后反复尝试不可用模型的问题，并让聊天记录里的删除真正移除整份渠道记录。

## 模型降级

- 同一轮回复中，一旦主模型失败并降级到备用模型，后续工具调用轮次会直接沿用降级后的模型，
  不再每轮重新请求已经失败的主模型。
- 同一轮内已经失败过的模型会被跳过，避免“主模型失败 → 备用模型恢复 → 下一轮又去撞主模型
  → 再次降级”导致耗时成倍增加。
- 新的用户消息与重新生成仍会从原主模型开始；设置页「失败自动切换模型」说明已同步更新。

## 聊天记录删除

- 「设置 → 聊天记录」左侧渠道列表的垃圾桶现在会删除整份渠道记录，并连同对应会话容器一起移除，
  不再只是清空消息后留下空条目。
- 删除前会显示明确确认；删除当前正在查看的渠道后会自动切换到其它渠道。
- 外部渠道之后收到新消息时会按需重新建立记录，长期记忆不受影响。

# 念风 Chat v2.0.1

本版是 v2.0.0 的补丁修复，主要解决插件安装、插件页状态与刷新体验问题。

## 插件安装

- 修复部分 zip 工具会在压缩包根部写入 `.` / `./` 目录条目，导致上传时被误判为“压缩包包含不安全路径”的问题。
- 这类根目录条目现在会被安全忽略，正常的插件目录结构仍照常校验并安装。

## 插件依赖与状态

- 必须依赖版本不匹配时，插件不再只标黄，而是直接标记为错误并阻止激活；未升级到当前核心版本的旧插件会明确标红并显示实际版本。
- 可选依赖版本不匹配仍然只提示黄色，不影响插件基础功能。
- 修复出厂内置插件被误标黄的问题：
  - `mobile-shell` 在桌面 / 非移动布局下也会正常注册服务；
  - `library-view` 正确注册服务，并移除对后端专用 `memory-store` 的无效可选依赖提示；
  - 仅信息级的自检提示（插槽拥挤、多个可选实现等）不再计入黄色告警。

## 刷新与加载体验

- 后端终端默认只输出 `info` 及以上日志，HTTP 访问等 `debug` 日志仍写入 `runtime.log` 和日志页。
- 前端默认只向后端转发 `warn` / `error`，浏览器刷新时不再把大量插件加载过程日志灌进后端终端；需要完整日志时可通过 `logs.clientForwardLevel` 调整。
- 插件页的“外部插件目录 / 添加插件 / 选择目录”等区域改为先渲染可用骨架，再异步读取目录，不再因 `health` 请求或后端扫描慢而长时间空白。
- 插件目录读取不再先等待一次健康检查，减少远程部署下的首屏等待。

## 升级说明

- 覆盖安装 v2.0.1 后重启后端即可；外部插件目录与用户数据不变。
- 旧版外部插件如果依赖当前核心版本的接口，会在插件页标红并提示实际版本，请升级到 2.0.x 对应版本。

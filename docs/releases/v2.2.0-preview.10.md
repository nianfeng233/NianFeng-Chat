# 念风Chat v2.2.0-preview.10

本次预览集中修复群管清理、本体更新与 QQ 渠道的单 @ 处理问题。

## 群聊清理

- 清理预告不再重复 @ 全体成员：无论文案模板是否自带 `@全体成员`，都只保留一个真实 at 消息段。
- 修复自动周期到点后不踢人的问题：预告发出后会按本轮对应的 18:00 执行，不会被下一个周期顺延。
- 清理结束后的反馈更完整：0 人可清理时会明确播报“没有发现需要移出的成员”；读取群成员失败也会发失败提示并继续播报下一轮时间。
- 旧版本遗留的异常待办（踢人时间被顺延到下一周期）在升级 / 刷新后不再傻等：检测到后会自动补发新一轮预告，等待配置的 `warnMinutes` 后执行。
- 新增直接执行待办：预告已经发过、正在等待踢人时，可选择不再补发预告，直接进入批量踢人与结果播报。

## 本体更新

- 更新前会确认旧实例真正退出；旧实例超时未退出时会主动结束旧进程，确认退出后才下载、替换并启动新版本。
- 更新助手等待超时也不会再与新实例同时运行，避免旧终端未关闭、端口 / 内存冲突。
- Web 更新解压优先使用 .NET `ZipFile` 流式解压，减少低内存环境或大更新包下 `Expand-Archive` 失败的概率。
- 更新响应异常、进度窗口残留等边界情况会正确清理，更新失败也会关闭更新进度窗口。

## QQ 官方机器人 / NapCat

- 只 @ 机器人、不发文字时，不再生成“无法解析正文 / 空消息”占位。
- 单 @ 会作为正常事件进入模型上下文，并提示模型结合最近的聊天记录自然回应，不再要求用户重新发送。
- 带引用的单 @ 会保留引用信息。

## 插件

- `napcat-group-guard` 升级到 v2.0.3，包含上述群聊清理修复。
- `qqbot` 升级到 v1.5.1，`napcat` 升级到 v1.0.2，`context-builder` 升级到 v1.0.1。
- 独立插件仓库的 `market.json` 内容哈希已同步更新。

## 版本

- 本体版本、桌面壳版本与 WebUI 运行时版本统一升级到 `2.2.0-preview.10`。

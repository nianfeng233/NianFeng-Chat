# 念风 Chat v1.1.2

本版本重点修复移动端布局、渠道输入状态、DeepSeek 思考模式工具调用、渠道敏感确认，并把运行日志升级为 AstrBot 风格的持久化终端日志。

## 修复与改进

- **手机端界面**：修复手机访问时会话 / 渠道主面板因 0 高标题栏行 / 0 宽 rail 列而整片空白的问题；设置页输入框、模型提供商、聊天记录等布局在窄屏下不再溢出或高度异常。
- **输入状态**：微信 clawbot 按 clawbot-manager 的 `sendtyping` 协议在整轮调用结束后发送 `status=0`；NapCat 私聊延长保活并在外发后补报；QQ 官方机器人跟随渠道能力。
- **DeepSeek 思考模式**：带 `tool_calls` 的历史 assistant 缺少 `reasoning_content` 时自动补空字段；遇到 reasoning_content 400 自动关闭思考并清理历史推理后重试。
- **聊天工作流**：强化 system prompt 与工具描述，明确“普通聊天一次 chat_send 后 end=true”的标准流程；严格工具模式最多纠正一次，仍不调用工具时直接按正文发送，避免一次普通聊天等待数分钟。
- **渠道授权**：同一会话 / 动作 / 目标的重复确认请求自动合并；身份 ID 支持 `qq:xxxx` 与纯数字互认；私聊主人渠道（NapCat 视为主人、QQ 官方 c2c、微信私聊）增加主人兜底，避免确认超时。
- **运行日志**：终端彩色输出 + `logs/runtime.log` + 内部 JSONL 索引 + WebUI：
  - 后端日志、前端 chat-flow / 工具 / 权限 / 外发日志统一进入同一日志流；
  - WebUI 通过 SSE 实时接收，轮询兜底；
  - 页面刷新、重启后端都会回读历史；
  - 默认展示 DEBUG 级细节，支持级别 / 分类 / 关键词过滤、暂停、复制、导出、清空。

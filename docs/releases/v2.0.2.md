# 念风 Chat v2.0.2

本版是 v2.0.1 的补丁修复，主要解决外部插件热更新和旧版插件状态判断问题。

## 外部插件热更新

- 修复 `ctx.effect(() => () => cleanup)` 形式的清理函数在插件热更新时没有执行的问题。
- 旧实例释放时会正确执行工具、设置页、事件监听等清理，不再出现旧实例残留。
- 修复更新或连续安装外部插件后，新实例报 `工具已注册：...`、`加载/运行失败：插件执行失败` 的问题。
- 修复插件页在热更新后残留红色状态的问题。

## 旧版外部插件兼容性

- 外部插件主版本必须与当前内核主版本一致，即念风 2.x 需要外部插件为 2.x。
- 外部插件版本为 1.x 或更低时，会被明确标记为 **旧版不兼容**：
  - 插件页标红，并显示当前版本和需要升级到的版本；
  - 不再激活，避免旧代码继续注册工具、面板或后台桥造成冲突。
- 之前旧插件只按“依赖版本范围”判断，很多旧插件声明了宽泛的 `>=` 范围，所以看起来是正常的；现在额外检查插件自身的主版本。
- 升级到 2.x 的新版插件后，插件页状态会自动恢复。

> **后续修正**：上面这条“外部插件主版本必须与内核主版本一致”的规则已经移除。
> 插件版本号和内核版本号是两套语义，不能因为插件仍是 1.x 就强制拦截。
> 现在只有插件显式声明 `minAppVersion` / `maxAppVersion` 且当前内核不满足时，
> 才会被标记为「内核不兼容」并阻止激活；未声明的插件按依赖、`inject` 与运行时结果正常处理。

## 其他

- 保留 v2.0.1 的修复：zip 根目录 `./` 条目、终端 debug 日志、插件目录首屏骨架、必须依赖版本不匹配标红等。
- 旧版插件数据不会删除；升级插件文件后重新扫描即可恢复。

## 升级说明

- 直接覆盖安装 v2.0.2 并重启后端。
- 外部插件目录与用户数据不变。
- 如果插件页仍有 1.x 外部插件标红，用对应的 2.x 版本插件包覆盖或重新上传安装。

## 新增

### 外部插件目录（不再需要重新打包）

- 后端新增 `plugin-registry`：启动时扫描内置插件目录 + 外部插件目录，合并为统一插件清单。
- 外部目录默认跟随数据目录：`<数据目录>/plugins/`（exe 为
  `%LOCALAPPDATA%\NianFengChat\user_data\plugins\`），也可在「设置 → 插件 → 插件目录」中指定
  任意目录，或用环境变量 `NIANFENG_PLUGINS_DIR`。
- 新增 API：`GET /api/plugins`、`GET/PUT /api/plugins/dirs`、`POST /api/plugins/rescan`、
  `/user-plugins/*` 文件服务、外部插件删除接口。
- 前端启动从 `/api/plugins` 取清单并动态加载外部插件；新增插件只需复制文件夹 + 重新扫描，
  exe 升级不会删除外部插件目录。

### WebUI 监听与访问令牌

- 「设置 → 网络 → WebUI 访问」新增监听地址（`127.0.0.1` / `0.0.0.0`）、端口与访问令牌。
- 访问令牌非空时：必须 `http://<主机>:<端口>/?token=xxx` 访问；验证通过写入 Cookie。
  `/api/health`、`/api/version` 免令牌，供宿主探活。
- 保存后弹窗询问是否立即重启；Web 版由启动脚本重新拉起，桌面版重启整个 exe。
- 桌面版通过 `<HOME>/.webui-token` 与 `<HOME>/.webui-port` 把实际令牌/端口交给 Rust 宿主，
  WebView 以正确地址打开。

### 通知系统

- 角色消息通知：左下/右上均带角色头像（自定义图片或首字色板）；系统通知同样把 64×64
  角色头像交给 Rust 宿主作为 Windows 通知大图标，风格对齐 QQ 等常见 IM。
- 桌面通知图标使用应用自身 `app.ico`，不再显示通用系统图标。
- 提示音支持内置音色（默认 / 清脆 / 柔和 / 双响）与自定义上传（mp3 / wav / ogg，
  保存到本机配置）。
- 保持三类通知样式：系统通知 / 角色消息 / 其他通知；每条角色消息都会按规则生成通知。

### 工程与合规

- 版本管理与发布规范：新增 `docs/RELEASING.md`。
- 发布安全门禁：`scripts/prepare-publish.mjs` 同步纯净源码并强制扫描用户名、本机路径、
  凭据、私钥、邮箱、手机号与用户数据文件。
- 一键发布：`scripts/publish-release.mjs`（提交 / tag / push / GitHub Release / 附件）。
- 许可证切换为 **Apache-2.0**，新增 `NOTICE`；第三方声明见 `THIRD-PARTY-NOTICES.md` 与
  `docs/DEPENDENCIES.md`。

## 变更

- 版本号：`0.40.0` → `0.41.0`（`package.json` 与桌面壳 `Cargo.toml` 同步）。
- 桌面壳：新增通知头像 IPC、exe 一键重启 IPC、WebUI 端口/令牌文件读取、关闭时最小化。
- `start.mjs`：读取数据目录 `config.json` 的 network 段，统一处理监听地址 / 端口 / 令牌 /
  进程重启。
- 发布仓库改为 `release/publish` 独立工作树，不再从 workspace 直接推送。

## 修复

- 修复 exe 系统通知没有角色头像、应用图标缺失的问题。
- 修复「浏览器通知权限」在 exe 中直接显示已拒绝的问题（桌面端由宿主直发，不再经过 WebView2 通知权限）。
- 修复通知测试只能看到文本、无法直观验证头像/图标的问题。
- 修复 v0.40.0 之前预编译 exe 中含开发机绝对路径的问题（remap 已在 v0.40.0 生效，本版保持并复核）。

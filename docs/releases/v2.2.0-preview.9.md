# 念风Chat v2.2.0-preview.9

本版本用于验证 v2.2.0-preview.8 引入的“先下载、显示进度、再替换”更新流程，并包含以下改进。

## 更新进度与体验

- 更新助手会先打开精简进度窗口，显示当前阶段、下载百分比和已下载 / 总大小。
- 桌面版会**先完整下载并校验更新包，再关闭旧窗口**；下载完成前旧窗口不会消失。
- Web 部署版和源码运行方式也会显示进度窗口，并在下载、解压、替换阶段分别提示。

## 可靠性

- `taskkill` 被系统策略拒绝时回退 Node 原生结束进程，并确认旧进程退出后再替换文件。
- 新桌面版启动后若立即退出，会自动回滚旧版本并重新启动。
- 更新助手工作目录不再锁定下载缓存；成功后会正常清理临时文件。
- 设置 `NIANFENG_NO_UPDATE_CONSOLE=1` 可关闭进度窗口。

## 测试说明

- 从 `v2.2.0-preview.8` 更新到本版本时，会使用 preview.8 内置的新版更新助手，可以看到完整进度窗口。
- 版本号统一升级到 `2.2.0-preview.9`。

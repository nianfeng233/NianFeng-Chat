# 念风 Chat v1.1.8

本版本把 preview 分支上的服务端常驻代聊、渠道能力增强、安全加固、工具严格模式、图片与上下文预算等更新整体汇总到 main，并补齐了一批稳定性修复。WebUI 关闭后，QQ / NapCat / 微信等渠道仍可由服务端代聊继续处理。

## 新功能

### 服务端常驻代聊（server-agent）

- 新增 `src/headless` Node 前端运行时：在 worker_threads 中用 DOM 垫片加载与浏览器相同的前端插件。
- `start.mjs` 默认启动服务端代聊并注册 `server-agent` 能力；关闭 WebUI / 浏览器后，渠道消息仍可正常接收与回复。
- 浏览器端渠道插件在检测到 `server-agent` 时让出入站消息处理权，避免重复回复。
- 服务端代聊写回的消息通过带 `agent` 标记的 `sessions/changed` 广播，浏览器打开后自动刷新会话。
- 外部插件安装 / 删除 / 重新扫描 / 切换目录时，自动重启代聊 Worker，新工具立即生效。

### 渠道能力增强

- **NapCat / OneBot 11**：
  - 支持合并转发（聊天记录）发送；资料与超长消息自动折叠为转发节点，阈值见 `chat.forward*`。
  - 出站正文支持 CQ 码白名单：`[CQ:at]` / `[at:qq]` / image / face / music / json / xml / reply 等，并阻断本地文件与危险字段。
  - 新增连接心跳看门狗、SSE 重连与定时补收，改善断线漏消息。
  - 启动前积压 / 回放消息默认只写入上下文、不触发自动回复（`napcat.replyBacklog=true` 可恢复旧行为）。
- **QQ 官方机器人 / 微信 Clawbot**：补齐入站图片、被动回复、绑定过滤与会话同步路径。
- **外部插件**：外部 `bridge.mjs` 支持热加载，前后端一起热插拔，不需要重启念风。
- **插件页**：新增上传 zip 安装外部插件，服务端完成路径穿越 / 体积 / 可执行文件校验后解压到外部插件目录。

### 工具与聊天链路

- 严格工具模式：模型只输出 assistant 正文不再被当作回复；`chat.toolRetryLimit` 默认 3 次纠正，仍不调用工具则复用 `chat_send` 标准发送链兜底。
- 提供商不支持原生 function calling 时，自动切换文本工具协议，而不是退化成裸正文。
- `send_document` 支持一次发送多篇资料（`documents` 数组）；NapCat 渠道按「标题 + 正文」合并转发。
- 新增 `read_forward` 分页深读转发记录、嵌套转发与长文续读；新增 `napcat_card` 卡片工具。
- 用户消息上下文增加工具回复提醒，降低模型直出正文的概率。

### 图片与上下文预算

- 自动上下文默认只保留最近 2 张原图，其余历史图片统一用 `[图片]` 占位；整轮请求默认最多 8MB 图片字节。
- `read_messages` 主动读图时才返回原图，模型 / 工具 / 渠道 / 适配器都不能绕过最终预算。
- 本地图片存储默认只保留最近 30 张，避免磁盘无限增长。
- 引用消息会带上发送者、时间、`message_id` 与原文；引用图片会按需下载并作为多模态原图注入。

### 模型与设置体验

- 模型页的「获取模型列表」改为临时候选：点击「添加」才写入配置，避免远端列表直接污染本地模型。
- 新增 `provider-model-discover` 后端能力与远端模型发现接口；旧后端缺少能力时会明确提示重启。
- `chat.contextTokens` 默认 0（不截断输入）；`chat.maxOutputTokens` 默认 8192，模型级 `max_tokens` 优先。
- `/api/chat` 默认请求体上限 32MB；超限返回明确的 413 原因，不再变成 502。
- DeepSeek `reasoning_content` 缺失补全、工具历史回传与 400 自动降级重试。
- 修复角色模型切换后必须重启才生效的问题（会话元数据按 `metaUpdatedAt` 合并）。

## 安全加固

- Host / Origin 校验：有效访问令牌放行远程访问；跨站 Origin 拒绝；带 `?token=` 的导航在已有 Cookie 时 302 清理地址栏。
- `/health` 脱敏、SSRF 防护、常量时间令牌比较、SSE 快速关停。
- 插件 zip 上传路径穿越、体积与可执行文件类型校验。
- 外部 bridge 明确标注为高权限本地 Node 代码，只加载可信插件。

## 稳定性修复

- `backend-client` 健康检查改为连续失败 3 次才判定离线，并放宽单次超时；EventSource 瞬断不再立刻把 WebUI 标成“后端不可用”。
- `session-service` 合并后端全量与本地滚动缓存，修复截断缓存覆盖历史、并发写盘临时文件冲突与「聊天记录全量后丢失」。
- 每条消息早退和异常路径也会发送 `chat:request-done`，避免渠道入站队列挂起。
- 修复远程访问令牌残留、旧会话 / 旧后端能力提示。

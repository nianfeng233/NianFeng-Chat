# 念风 Chat v1.1.0

v1.0.0 之后的稳定版本，重点修复“渠道消息看似发出、实际没到”的链路问题，并补齐输入状态、运行日志、手机端与空回复处理。

## 渠道与消息链路

- **渠道消息即时外发**：助手消息写入目标渠道会话后立即按顺序发送，不再等整轮模型调用结束；跨渠道 `chat_send` / `send_document` 会真正发送到目标渠道。
- **逐条消息节奏**：网页端与外部渠道统一为“每轮首条立即发送，后续消息按内容长度模拟真人打字延迟”。
- **外发失败可见**：渠道外发失败会写回 `outboundError`，并在会话中追加一条失败提示；运行日志页同步显示失败原因。
- **工具结果补充队列状态**：外部渠道工具返回增加 `delivery: queued`，说明消息已进入外发队列，而不是已确认送达。

## 输入状态

- **微信clawbot**：整轮调用期间保持“输入中”；发送授权提示 / 回复消息后自动补报，只有整轮彻底结束才停止。
- **NapCat 输入状态插件**：新增 `napcat-input-state` 扩展，私聊渠道按固定间隔刷新 `set_input_status`，整轮结束后停止；群聊接口不支持，插件会自动跳过。
- 保留输入状态配置：刷新间隔、最长持续时间、开关。

## 空回复与模型调用稳定性

- 对齐 DeepSeek 官方 harness 的空响应处理：`finish_reason=stop` 且没有正文、没有工具调用时判定为 `EMPTY_RESPONSE`。
- 后端会自动重试空回复（默认 1 次，可配置 0 / 1 / 2 / 3 / 5 次），重试期间不把空白流写入界面。
- 重试仍为空时抛出明确错误，并把错误原文发回来源渠道，不再静默结束让用户干等。
- 前端 `chat-flow` 额外支持空回复纠正：移除空占位气泡，最多追加 2 次系统纠正；仍为空则写入“模型连续返回空回复，本轮已停止”提示。
- `chat_send` / `send_document` 过滤不可见字符，避免零宽字符生成空消息。
- DeepSeek 思考模式继续按官方要求回传 `reasoning_content`，不发送 `tool_choice`。

## 运行日志

- 后端新增 `runtime-logs` 插件：所有 cordis 后端日志进入环形缓冲并写入 `<数据目录>/logs/runtime.log`，超过 5MB 自动轮转。
- SSE 新增 `log/line`，运行日志页可实时接收并拉取后端历史。
- 日志页支持级别 / 分类 / 关键词筛选、暂停、清空、复制和导出 `.log`。
- 模型阶段、工具耗时、权限确认、渠道外发、后端请求与超时都会显示，便于判断卡在哪一步。

## 手机端

- 手机访问自动进入单栏界面：隐藏桌面侧栏 / 拖拽条，改为顶部返回栏 + 底部「会话 / 渠道 / 设置」导航。
- 设置页改为横向导航 + 全屏内容，适配 9:16 竖屏、底部安全区与键盘弹出。
- 手机端所有右键操作改为长按触发（消息、会话、渠道、分组）。
- 支持 `?mobile=1` / `?mobile=0` 强制调试。

## 设置与交互

- 新增「设置 → 系统 → 渠道授权」：集中管理跨渠道读取 / 发送、手动授权记录与审计日志。
- 设置侧栏新增搜索框。
- 会话列表新增批量管理：多选、全选、批量删除、导出选中。
- 输入草稿按会话独立保存，切换会话不再串文本或丢失附件。
- `general.restore` 默认关闭；即使开启，也不会在启动时自动进入渠道记录会话。
- 消息删除、渠道移除增加二次确认。
- 聊天记录 JSON 模式增加高风险确认，并支持「恢复上次保存前」。
- 网络设置新增 0.0.0.0 空令牌安全提示。
- 敏感操作确认超时会写入“已超时，自动拒绝”消息。
- 模型调用失败会把原始错误内容回写到对应渠道。
- 会话本地缓存改为节流写入，页面隐藏 / 卸载时强制 flush。
- QQ 官方机器人移除本地“允许主动消息”开关，被动回复窗口失效时自动尝试主动消息（受 QQ 官方额度限制）。

## 清理

- 官方服务插件移出仓库，保存在开发机本地工作区，不推送 GitHub、不参与打包；模型页默认直接显示自定义提供商配置。
- 移除早期测试用的 `extensions/wechat-clawbot` 独立分发包及对应打包脚本。

## 升级说明

- 升级后请完全重启念风（包括后端进程），让空回复重试与渠道即时外发逻辑生效。
- 之前已在聊天记录中存在、但实际未送达的空白 assistant 消息不会自动删除，可在「设置 → 聊天记录」中手动清理。
- 如使用 NapCat 私聊输入状态，请在「设置 → 插件 → NapCat 输入状态」中确认开关和刷新间隔。
- 如需调整空回复行为：在「通用 → 空回复纠正次数」设置前端纠正次数；后端同一请求的自动重试保留内部默认一次，不再单独暴露配置。

# 念风 Chat v1.1.9 Preview 2

> 这是 preview 分支的预发布快照，用于提前验证 v1.1.9 的长期记忆更新；正式发布请以 `v1.1.9` 为准。
> 本预览版与 v1.1.9 使用同一份源码构建，详细更新内容见 `docs/releases/v1.1.9.md`。

## 本版重点

- **群聊记忆窗口策略**：每次模型轮结束后，按「最近 N 条群聊消息」检查 message_id；
  与已概括记录重复超过 `N-5` 条时跳过，重复不超过 `N-5` 条时才把整个窗口交给概括模型。
  默认 N=20，即重复 >15 条不总结、≤15 条总结；不会出现“没触发模型也在总结”的定时器。
- **记忆人名称修复**：概括 prompt 使用真实角色名与消息 sender_name，不再把应用名“念风”
  写死成 assistant 标签，避免角色名不叫念风时记忆概括里出现“念风”。
- **长期记忆管理页**：侧栏「记忆与知识库」视图列出记忆概括，展开可查看对应消息原文快照。
- **会话与聊天记录稳定性**：修复渠道容器竞态、聊天记录分页与本地滚动缓存互相覆盖的问题。
- **模型与记忆模型设置**：长期记忆支持向量模型；概括模型可单独指定。

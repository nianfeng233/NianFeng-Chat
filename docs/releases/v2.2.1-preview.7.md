# 念风Chat v2.2.1-preview.7

本版集中修复手机端滚动、聊天记录管理，并补齐 B站、QQ 官方 / NapCat 与外部插件之间的媒体发送能力。

## 手机端滚动

- 日志页、聊天记录页恢复内层滚动：日志列表、渠道列表、消息卡片都能独立连续浏览。
- 内层滚到顶部 / 底部后继续同方向滑动时，滚动余量会通过 `overscroll-behavior-y:auto`
  与触控 / 滚轮兜底自动交给外层设置页，内外层滚动互不干扰。
- 调整手机端布局：工具栏、列表上下留白、底部说明区域保留足够面积，方便单独触发外层滚动；
  长列表不再需要先滑到页面特定位置才能继续往下看。

## 聊天记录

- 聊天记录列表按角色分组，分组标题使用角色会话的稳定名称，不再跟随最新渠道名变化。
- 每个渠道行展示更细致的渠道名与渠道信息（类型、会话类型、UID / QQ / openid、消息数、最近活跃时间）。
- 新增每渠道垃圾桶按钮，确认后快速清空该渠道整份聊天记录；新增
  `chat-store.clearMessages(channelId)`，不会断开渠道或删除长期记忆。

## B站渠道（bilibili v1.7.0）

- 私信与评论按对端 UID 统一入同一聊天记录库：同一个人在不同视频下的 @、评论与私信进入同一渠道；
  新的人 @ 机器人才会新增渠道。
- @ / 评论通知会实时从 B站拉取当前评论所在楼层的父级链，并作为
  「视频信息 + 相关评论树」顶层 user 消息进入上下文；只保留当前评论相关的那一条链，
  同层其他人的回复不会混入。
- 兼容旧版本按视频线程拆出的会话，找到同 UID 旧会话后迁移复用。

## QQ 官方 / NapCat / 外部插件

- QQ 官方机器人渠道支持发送视频（`file_type=2`）与文件（`file_type=4`），
  与原有图片、SILK 语音一起构成完整富媒体发送能力。
- NapCat 渠道支持结构化视频、文件、语音消息段；合并转发后也能追加视频 / 文件 / 语音。
- `chat_send` 支持 `images` / `videos` / `files` / `audios` / `attachments` 多格式附件，
  只发媒体、不写正文时也能正常发送。
- `media-post v2.2.0`：B站 / 抖音视频与文件在 QQ 官方机器人渠道改为富媒体直发，不再降级成链接。
- `napcat-like v2.1.0`：`qq` / `group` 定向发送（无需目标已注册为渠道）扩展到
  文本、图片、视频、语音与文件，并运行时补全 `chat_send` 的媒体 schema。

## 其它修复

- 修复后端全量拉取消息时未合并本地 pending 消息，导致刚发送的消息在
  `read_messages(image_message_ids=...)` 中“找不到”的竞态。
- 系统提示词注入当前渠道与其它渠道的媒体发送能力，明确 NapCat 使用 QQ 号 / 群号、
  QQ 官方机器人使用 openid，避免模型用错目标或只回链接。

# 念风Chat v2.2.0-preview.7

本次预览修复 QQ 官方机器人图片消息与 WebUI 刷新后长时间加载的问题，并补充相关回归测试。

## QQ 官方机器人

- 兼容新版 `msg_elements`：普通图片消息、`message_type=103` 的引用消息都能提取正文与附件。
- 引用消息里的图片会下载并转存到 image-service，不再生成“插件无法解析正文”的占位消息。
- `read_messages` 支持按 `image_message_ids` 回捞只有 `imageId` 的原图，并返回对应消息本身。

## WebUI 通信与刷新

- 新增全局 EventSource 多路复用：相同 `origin + pathname` 的 `/api/events` 共用一条 SSE 连接，多个渠道插件和外部插件不再占满浏览器同源 6 条连接池。
- 修复浏览器刷新 / 关闭页面后，反向代理上游 SSE 未销毁、后端 hub 持续堆积悬挂客户端的问题。
- WebUI 刷新、切换页面、模型流式回复期间，普通 `/api/*` 请求更不容易排队等待。

## 测试与构建

- 新增 `test-event-source-multiplex`：验证 EventSource 复用、事件分发、连接重建。
- 新增 `test-web-proxy`：验证代理 REST 转发与浏览器断开 SSE 后上游连接释放。
- `npm test` 全量通过；Web 版与桌面 EXE 重新打包构建。

## 版本

- 项目版本、运行时版本、桌面壳版本统一升级到 `2.2.0-preview.7`。

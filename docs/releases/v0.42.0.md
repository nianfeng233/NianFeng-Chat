# 念风 v0.42.0

## 新增与改进

- **微信 clawbot 渠道**
  - 每次获取二维码都会生成新的 `loginId` / ticket / 独立连接，不再把本机旧 token 传给微信，重新接入时微信会正常提示解除旧连接。
  - 多个 clawbot 渠道可同时在线，分别使用独立 token、同步游标与长轮询；重启后自动恢复全部渠道。
  - 修复“实际已接入但界面仍显示连接中”：`/login/status` 返回真实链路状态，前端扫码弹窗持续轮询到 online。
  - 删除渠道 / 删除分组会同步清理后端登录凭据与长轮询。
- **渠道数据跨 web / exe 共享**
  - 渠道分组与渠道实例除 localStorage 外，同步写入数据目录 `config.json` 的 `preferences.app.channels`，按 `updatedAt` 取新。
  - exe 中已创建的渠道首次启动新版后会自动迁移发布到共享数据目录；web 版（同一数据目录）可直接看到。
- **渠道权限**
  - 渠道设置里的“跨渠道读取 / 发送”直接生效，无需手工维护权限表；`sensitiveConfirm` 控制是否二次确认。
  - 确认提示会明确说明目标渠道类型和名称（网页渠道 / 微信clawbot），不再只显示角色名。
  - 微信侧会收到确认提示，直接回复“确认”即可放行。
- **聊天记录**
  - 渠道详情和插件设置里的「打开聊天记录」跳转到设置 → 聊天记录，并定位到对应渠道。
  - 聊天记录图形视图每条消息新增删除按钮；删除先进入草稿，点「保存」后写回，点「取消修改」可恢复。
- **上下文与持久化修复**
  - 修复 `Messages with role 'tool' must be a response to a preceding message with 'tool_calls'`：截断历史时自动修复孤立 / 不完整的工具协议消息序列。
  - 前端渠道数据、会话数据、配置偏好与后端共享数据目录的合并策略更稳；关闭 exe 时 Windows 桌面壳使用 `taskkill /T` 结束进程树。
- **项目更名**
  - README、文档、界面、通知、构建产物与发布说明统一为 **念风 / 念风Chat / NianFeng-Chat / nianfeng-chat**。
  - 旧版本环境变量与旧安装目录仅保留一次性兼容迁移能力，不再作为产品名称出现。

## 升级说明

- 直接替换 exe 或解压覆盖 Web 部署目录；`user_data`、渠道配置、聊天记录与外部插件目录保持不变。
- 如果 Web 版曾单独创建过渠道，首次启动新版后会自动与共享数据目录合并，按更新时间取新。

# 念风 Chat v2.0.3

本版重点修复群聊上下文里的发言人身份识别问题。

## 群聊发言人身份

- 每条群聊 user 消息正文开头新增系统身份标注：
  - 普通历史消息：`【发言人：昵称（QQ号）】`
  - 本轮必须回复的消息：`【本轮发言人：昵称（QQ号）】`
- 发言人元数据会同时写入结构化信封：
  - `meta.speaker_label`
  - `meta.user_name` / `meta.user_id`
  - `meta.is_owner`
  - `meta.group_id` / `meta.group_role`
- `content.speaker` 会保留昵称、QQ号、角色与是否主人本人，便于模型交叉核对。
- 群聊 system prompt 增加明确规则：
  - 不同昵称 / QQ 号是不同的人，不能把 A 的话算到 B 头上；
  - 历史消息里的“我 / 我的”只属于那条消息的发言人；
  - 只有 `meta.is_owner=true` 的消息才是主人本人；
  - 无法确认时按普通群友处理，不能因为熟悉或语气亲近就把对方当成主人。

## 主人身份匹配

- 如果渠道 / 全局用户身份配置了 QQ 号或用户 ID，发言人与之匹配时会标记：
  - `meta.is_owner=true`
  - 正文标注 `【发言人：昵称（QQ号），主人本人】`
- 若没有可用的数字 / 渠道 ID，只会在昵称完全一致时才认主；否则不强行判定，避免同名成员被误认成主人。
- 建议在渠道身份或全局用户身份里配置真实的 QQ 号 / 用户 ID，让群聊主人识别更稳定。

## 其他

- 保留 v2.0.2 的修复：外部插件热更新清理、旧版主版本不兼容标红等。
- 本版不改变用户数据与外部插件目录，覆盖安装后重启后端即可生效。

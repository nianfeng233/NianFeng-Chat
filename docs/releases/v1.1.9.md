# 念风 Chat v1.1.9

本版聚焦长期记忆与聊天记录稳定性。

## 长期记忆

- 角色级长期记忆库按角色独立存储（`memory.db` / `memory.json`）：普通渠道每 N 轮完整对话生成一条短概括并保存原文快照。
- 群聊记忆窗口：每次模型轮次结束后，检查最近 N 条群聊消息的 `message_id`；窗口与已保存记忆重复超过 `N-5` 条时跳过，否则为整个窗口生成一条概括。默认 N=20。
- 混合检索：支持向量语义 + BM25 关键词 + 时间过滤的 RRF 融合；未配置向量模型时自动使用关键词检索。
- 概括中的说话人使用真实角色名和消息发送者名，减少多人对话里的指代歧义。
- 「记忆与知识库」视图：记忆库标签页列出概括并可展开查看原文快照；知识库标签页在安装扩展后浏览全文、标签与历史版本。

## 会话与聊天记录

- 后端启动时自动合并同渠道的重复会话容器，修复历史消息挂载异常。
- 会话列表只同步 compact 元数据，聊天记录首屏按页加载，向上翻阅时再拉取更早内容。
- 合并后端全量与本地滚动缓存，降低本地缓存与远端历史互相覆盖的风险。
- 群聊上下文按消息条数计算（默认 20 条），更贴近群聊场景的上下文窗口。

## 模型与渠道

- 长期记忆的概括模型与向量模型可在设置中单独指定。
- DeepSeek / OpenAI 兼容 / Anthropic / Gemini / Ollama 的协议适配继续完善，覆盖工具历史、推理内容与参数降级。
- NapCat / QQ 官方机器人 / 微信 clawbot 渠道继续优化图片、回复与连接稳定性。

# 念风Chat v2.2.1-preview.6

本版新增 WebUI 新版本更新公告弹窗，并延续 preview.5 的更新流程修复。

## 更新公告弹窗

- 每次进入 / 刷新 WebUI 时会检测新版本：
  - 检测到兼容的新版本后，弹出更新公告；
  - 标题显示新版本 tag（例如 `v2.2.1-preview.6`）和当前版本；
  - 弹窗正文展示对应 GitHub Release 的更新说明，可滚动查看完整内容；
  - 底部提供「查看完整 Release 说明」「暂不更新」「前往更新」。
- 自动检测会强制刷新 Release 列表（失败时回退后端缓存），已发布的新版本在下次打开 / 刷新 WebUI
  时即可提示；如果同一基础版本同时存在正式版和更新的预览版，选择发布时间较新的 Release。
- 点击「前往更新」：
  - 自动跳转到欢迎页「版本与更新」区域；
  - 自动在目标版本下拉框中选中本次提示的 Release，便于直接更新。
- 点击「暂不更新」、关闭遮罩或按 Esc：
  - 记住当前提示的 Release tag；
  - 下次刷新 / 重开 WebUI 不再弹出同一个版本；
  - 之后发布了更新的版本时，仍会重新弹出新的更新公告。
- 弹窗顶部固定展示：
  - 官方交流群号 `1109357470`；
  - 「本项目完全免费、开源发布」声明；
  - 「付费购买请立即申请退款并举报」提醒。
- Release 接口新增 `body` / `htmlUrl` 字段，供弹窗展示更新说明；过长正文会自动截断，避免接口膨胀。

## 更新流程

- 保留 preview.5 的旧启动窗口自动收尾逻辑：
  - 发布包启动脚本带 `NIANFENG_LAUNCHER=1` 标记；
  - 更新助手替换 `启动念风.cmd` 前先等待 / 关闭旧启动窗口，避免旧 cmd 读到半更新文件后报
    `Not enough memory resources are available to process this command.`；
  - 启动脚本异常退出时 10 秒后自动关窗，不再无限 `pause`。
- 如果希望保留旧终端，可在启动前设置 `NIANFENG_KEEP_OLD_TERMINAL=1`。

## 测试

- 新增更新公告回归测试：覆盖弹窗内容、交流群 / 免费声明、暂不更新记忆、同 tag 不重复弹、
  新 tag 重新弹等场景。
- 保留更新助手回归测试：覆盖专用启动窗口自动关闭、普通终端不误关等场景。

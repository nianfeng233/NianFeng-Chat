# 念风Chat v2.2.1-preview.1

> 预览版：v2.2.0 之后的补丁修复与缓存架构优化，用于验证「本体 / 插件升级后仍然加载旧页面、旧代码」问题，并为本体增加外部服务回调所需的基础能力。

## 缓存与更新

- WebUI 入口按后端启动构建号加载整套模块：本体升级或重启后，浏览器、反向代理与 HTTP 缓存中的旧版本 URL 自动失效，不会再出现界面已经升级、打开却仍是旧页面的情况。
- 外部插件模块改为按版本路径加载，插件的相对引用会一起进入新版本路径；插件只更新 `lib/` 里的文件也能正确失效旧模块。
- 插件清单缓存会校验后端构建号，本体升级后不会再用升级前的旧插件清单启动。
- 静态资源的 ETag / gzip / 强缓存策略保持原有性能优势，同时保证版本变化时立即刷新。
- 服务端代聊 Worker 会在插件代码签名变化时重启，确保 Node ESM 不会继续运行旧子模块；仅启停偏好变化仍走热同步。

## 插件能力

- 后端 HTTP 框架新增公开 Webhook 路由能力：外部服务可以在 `/api/webhooks/*` 下回调已注册的插件路由，并由插件自行完成路径密钥与签名校验。
- GitHub 助手 v2.1.0 可使用 Webhook 低延迟订阅：GitHub 动态即时回调，轮询自动降为兜底；未升级插件不影响本体使用。

## 升级说明

- 直接覆盖安装本预览版即可，数据目录、会话、模型配置与已安装插件均不受影响。
- 使用 Webhook 低延迟订阅需要公网可达的回调入口；未配置时继续使用原有轮询，不需要额外操作。

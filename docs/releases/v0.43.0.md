# 念风 v0.43.0

> 发布日期：2026-09-12
> 官方 QQ 群：1109357470

## 新增与优化

### QQ 官方机器人渠道（新）

- 支持扫码接入（`q.qq.com/lite/create_bind_task` + `poll_bind_result`）与手动 AppID / AppSecret 接入；
- 支持 WebSocket 本地直连与 Webhook 回调，当前范围只做 QQ 私聊（C2C）；
- 扫码账号正式环境被 IP 白名单拒绝时自动切换到沙箱 OpenAPI（`sandbox.api.sgroup.qq.com`），
  本地部署免白名单、免公网；
- 支持 QQ Connector 1.2.0 的 `user_openid`：自动绑定模式会直接把扫码用户绑为渠道默认会话；
- 未绑定 / 多候选 / 未匹配绑定的私聊会自动回一条引导消息，提示到 WebUI「发现会话」复制 openid 并绑定，
  同一个 openid 10 分钟内只提醒一次；
- 删除渠道会同步清理对应的聊天记录容器，启动和渠道同步后也会清理没有对应渠道的孤立记录，聊天记录页不再残留空渠道；
- 图片收发、被动回复 `msg_id + msg_seq` 上限、渠道级权限与隐私隔离全面接入念风聊天链路。

### 图片与多模态链路

- 新增通用图片服务 `image-service`：图片落盘保存、压缩、按需转 data URL、`/api/images` 读写；
- 消息只保存 `imageId`，避免 base64 写进 `sessions.json` 与协议轨迹；
- Web 输入支持图片上传 / 粘贴 / 拖拽与压缩预览，气泡渲染图片；
- 模型上下文支持多模态图片预算、历史图片占位、工具按需读取图片；
- OpenAI / Claude / Gemini / Ollama 请求格式统一适配图片输入与输出。

### 微信 Clawbot 渠道

- 完善扫码长轮询、连接状态、渠道列表刷新、插件依赖与用户身份；
- 支持用户显示名 / 用户唯一标识，默认跟随统一 `user-identity` 服务；
- 渠道会话从普通会话列表隐藏，避免同一角色出现双入口、双份消息；
- 完善 typing 状态、敏感操作确认与渠道记录跨端持久化；
- 断开 / 删除渠道时正确清理登录凭据与聊天记录容器。

### 模型与设置体验

- 修复模型设置页因 `selectable` 配置重复写入导致的反复刷新问题，输入框可正常停留与编辑；
- 模型注册表 `replaceModels` 增加差异比较，模型无变化时不再重注册全部可选中模型；
- 模型适配器同步时避免重复选择与无意义广播；
- 修复「重新扫码绑定」二次确认被压在接入弹窗下层的问题，并避免关闭接入弹窗后继续创建二维码任务。

### 桌面端与发布

- 桌面壳关闭按钮改为快速隐藏 + 异步 `taskkill` + `CREATE_NO_WINDOW`，不再同步等待、不再闪黑窗；
- 每次构建使用独立运行时目录，避免旧 `node.exe` 占用导致新 exe 双击无反应；
- 支持自定义 release 输出目录，旧 exe 运行时也能重新打包；
- README 增加官方 QQ 群：1109357470。

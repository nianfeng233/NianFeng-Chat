# 念风Chat v2.2.0-preview.1

本次预览主要围绕 QQ 官方机器人渠道的群聊补全、路由稳定性与渠道自检。

## QQ 官方机器人 · 群聊

- 支持 `GROUP_MESSAGE_CREATE` 全量群消息：群管理员开启「机器人可获取群内全部消息」后，未 @ 机器人的普通消息也会进入渠道聊天记录并参与群规则判断；@ 消息继续走 `GROUP_AT_MESSAGE_CREATE`。
- 群聊规则对齐 NapCat 口径：
  - 「仅 @ 时回复」：关闭后普通消息按概率触发；
  - 「被 @ 时必定回复」：默认开启，可关闭改为让 @ 也参与概率 / 白名单；
  - 支持黑名单、白名单、@ 白名单限制、概率白名单、上下文条数、未触发时静默写入。
- 「回复时引用触发消息」与「回复时艾特触发者」改为真正的独立开关，默认关闭；群回复默认走主动消息，不会强制引用，主动额度不可用时自动回退被动回复。
- 修复群消息的绑定同步与路由：
  - bridge 已路由到本渠道、但本机绑定列表未同步时，不再静默丢弃；
  - 同一会话只归属最后一个保存它的渠道，自动清理重复绑定；
  - 启动时清理后端已经不存在于前端的渠道配置，避免已删除渠道继续抢路由；
  - 全量事件正文解析失败时生成占位消息并记录 payload keys，不再无提示丢失。
- 渠道详情新增自检信息：后端连接、后端插件版本、最近事件、最近入站、路由冲突；发现会话里被其它渠道绑定的会话会标记「已绑定到其它渠道」，可一键「改绑到本渠道」。
- 新增「重连网关」按钮，群权限或连接状态变化后无需重启整个应用即可重新 Identify。
- 修复未绑定私聊提示文案中的项目名错误（念心Chat → 念风Chat）。

## 长期记忆与点歌台

- 修复群聊逐渠道「记忆总结」关闭不生效：设置页保存的是裸渠道 id，而 chat-store 内部可能使用带类型前缀的 id，现在两种键都会命中。
- 修复 QQ 官方机器人语音发送成功后，工具结果缺少明确成功标记 / message id 时模型可能误判为“没有发出去”的问题；语音成功结果现在带 `success: true` 与明确的成功说明，并兼容 QQ 接口的多种 id 字段。

## 兼容性与升级说明

- 现有 QQ 官方机器人渠道会在启动时自动迁移群规则：引用 / 艾特回复默认关闭，@ 默认必定回复；之后可在渠道编辑中自行调整。
- 桌面版、Web 版与后端 bridge 需要一起更新；`bridge.mjs` 改动必须重启后端进程才会生效。

# 念风Chat v2.2.1-preview.4

本版继续 v2.2.1 预览线，集中修复群管白词优先级、QQ 官方机器人艾特能力、移动端界面、日志同步，并增加版本更新通知与免费声明弹窗。

## 群管助手

- **进群白词优先级高于黑词**：同一句入群回答同时命中白词和黑词时按白词放行，不再误拉黑；只有未命中白词时才执行黑词拦截。
- 更新设置面板与 README 的规则说明，补充对应断言。
- 版本号提升到 `2.0.7`。

## QQ 官方机器人

- 群聊规则新增「艾特方式」：
  - **文本 @ 群昵称**（默认，兼容性最好）；
  - **QQ 原生 @（实验性）**：使用事件里的 `member_openid` 尝试官方 `<@!member_openid>` 语法；若某些 QQ 版本未渲染成 @ 气泡，改回文本 @ 即可。
- 渠道详情展示当前生效的回复艾特方式。
- 版本号提升到 `1.6.0`。

## 移动端界面

- 修复持久化激活 `logs` / `welcome` 等全宽视图时，移动端首次进入空白、切走再回来才显示的问题（全宽视图注册后重新计算单栏状态）。
- 修复移动端在渠道条目上拖动时触发渠道拖拽排序、导致渠道列表无法上下滚动的问题；触摸/触控笔只保留原生滚动，鼠标仍可拖拽排序。
- 渠道详情插槽统一负责纵向滚动：内置详情与 NapCat / QQ 官方 / 微信自定义详情都能完整下翻，不再被父面板裁切；补全自定义详情留白。
- 移动端补充渠道详情、键值表、绑定行、文本域、底部导航等适配，长内容可滚动、按钮不再被挤出屏幕。

## 日志同步

- 日志页默认级别改为与后端终端一致：**错误 / 警告 / 信息**；旧版「只看信息」默认值只迁移一次，之后尊重用户选择。
- 后端 `runtime.log` 的日志行按原级别原样展示，不再单独吞掉 HTTP 访问行；终端默认能看到的内容，日志页默认也能看到。
- 后端日志接口返回当前终端级别，日志页状态栏显示「页面筛选级别 / 终端默认级别」，便于对照。

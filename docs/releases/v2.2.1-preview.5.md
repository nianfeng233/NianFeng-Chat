# 念风Chat v2.2.1-preview.5

本版修复本体更新时旧启动窗口残留的问题。

## 更新流程

- 修复更新完成后旧 cmd 窗口一直停在 `D:\...\deploy>` 提示符的问题：
  - 发布包启动脚本新增 `NIANFENG_LAUNCHER=1` 标记；
  - 更新助手在旧实例退出、替换文件前，会先等待启动它的旧窗口自然关闭；带标记但未自动退出的专用启动窗口会被主动结束；
  - 未带标记的源码 / 手动启动终端不会被误关，最多只等待旧窗口自然退出。
- 修复旧窗口在替换 `启动念风.cmd` 期间读到半更新文件，出现
  `Not enough memory resources are available to process this command.` 并卡在提示符的问题：
  现在替换启动脚本前会先关闭旧启动窗口，不再发生读写竞争。
- 生成版启动脚本在程序异常退出时不再无限 `pause`：会显示退出码，并在 10 秒后自动关闭窗口。
- 如需保留旧终端（例如在已有终端里开发调试），可以在启动前设置
  `NIANFENG_KEEP_OLD_TERMINAL=1`。

> 注意：首次从 preview.4 或更早版本更新到本版时，更新过程仍由旧版更新助手执行，
> 因此第一次升级后旧窗口可能仍需手动关闭一次；从本版开始，后续更新会自动关闭旧启动窗口。

## 其他

- 新增更新助手回归测试：覆盖专用启动窗口自动关闭、普通终端不误关、旧窗口已退出等场景。
- 版本号升级到 `2.2.1-preview.5`。

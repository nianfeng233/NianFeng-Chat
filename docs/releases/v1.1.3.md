# 念风 Chat v1.1.3

本版本聚焦手机端 WebUI 布局比例与多端设置实时同步，修复模型页设置项被桌面端 flex-basis 撑出大片空白，以及电脑端修改推理等级后手机端仍显示旧值的问题。

## 修复与改进

### 手机端设置页布局

- 模型设置页的 `.setting-main` / `.setting-control` 在桌面端使用 `flex:1 1 150px` / `flex:1 1 240px`；手机端行布局改为竖向排列后，这些 flex-basis 会变成 150px / 240px 的“高度”，导致一个设置行被撑到 400px 以上。现在统一重置为 `flex:0 0 auto`，高级配置、保存按钮、模型列表重新回到正常间距。
- 模型页提供商列表在手机上改为横向可滑动选择条，隐藏侧栏删除按钮（删除入口仍在详情区），不再占据首屏大半高度。
- 设置页控件整行宽度、模型详情按钮换行、插件卡片操作区换行、外观玻璃滑动条等窄屏适配补齐；设置页横向导航在打开 / 切页时自动把当前项滚动到可视区域。
- 聊天区同步收窄：消息区左右留白、头像尺寸、输入框工具栏 / 发送按钮 / 气泡换行更符合手机比例。
- 新增 CSS 回归断言，防止模型页再次出现“150/240px flex-basis 撑高度”的空白问题。

### 多端设置实时同步

- 后端 `config.json` 新增 `preferencesMeta`，为每个偏好键记录最近更新时间与来源。
- `PUT /api/config` 按 per-key 时间戳合并偏好：旧页面 / 慢页面的整包推送不会再覆盖另一端刚改的新值；旧版本无时间戳数据按远端优先，便于升级纠错。
- 前端 `config` 插件订阅后端 SSE `settings/updated`，电脑端修改后手机端无需刷新即可实时更新；`app.channels` 继续按 `updatedAt` 整体取新。
- `bindConfigControls` 为所有开关 / 分段 / 下拉 / 输入框增加 config watcher；模型页推理等级、temperature 滑块也实时刷新，修复“电脑拉 high、手机显示无、刷新也没用”的根因。
- 本机专属偏好（`backend.url`、`chat.composerHeight`、`view.active`、`view.width.*`）不再推送到共享配置，避免不同设备的窗口 / 视图状态互相覆盖。

# 念风Chat v2.2.0-preview.8

本次预览重点优化本体更新的等待体验与失败恢复，解决“更新时窗口先消失、随后长时间没有任何反馈”的问题。

## 更新流程

- 桌面版更新改为**先完整下载并校验更新包，再关闭旧窗口和替换文件**；下载完成前旧实例不会被结束。
- 更新助手会额外打开一个精简的进度控制台窗口，显示当前阶段、下载百分比、已下载大小 / 总大小。
- Web 部署版和源码运行方式同样会显示进度窗口，下载、解压、替换阶段都有明确提示。
- 下载失败、解压失败、替换失败或新版本启动失败时，会在进度窗口显示错误，并尽力重新启动旧版本。
- `taskkill` 被系统策略拒绝时，会回退到 Node 原生结束进程，避免旧窗口没关掉就继续替换文件。
- 新桌面版启动后会观察一小段时间；如果进程秒退，会自动回滚到旧版本并重新启动。

## 进度窗口

- 桌面版更新会弹出类似下图的简易进度窗口：

```text
  念风 Chat 正在更新

  阶段：正在下载更新包
  进度：[##########--------------------------] 25.6%
  大小：24.5 MB / 95.7 MB

  已下载 24.5 MB / 95.7 MB
```

- 设置 `NIANFENG_NO_UPDATE_CONSOLE=1` 可禁用进度窗口。

## 临时目录

- 更新助手不再把自身工作目录设为临时更新目录，成功后会正常清理下载缓存，避免长期残留几十 MB 的更新包。

## 版本

- 项目版本、运行时版本、桌面壳版本统一升级到 `2.2.0-preview.8`。

# 念风Chat v2.3.0-preview.1

本版为 NapCat 渠道增加私聊 / 隐私目标名单模式：既可以继续只回复指定 QQ，也可以让机器人回复账号下的所有 QQ，并支持忽略名单与静默入库。

## 私聊 / 隐私目标模式

- 添加 / 编辑 NapCat 渠道时，私聊与隐私分类新增「白名单 / 黑名单」选择：
  - **白名单（默认）**：只有名单里的 QQ 私聊会进入渠道并触发回复，行为与旧版一致；
  - **黑名单**：名单里的 QQ 不触发回复，留空表示回复该账号下所有 QQ 私聊。
- 两种名单都支持多个 QQ，使用逗号、中文逗号或空格分隔。
- 旧渠道会自动按白名单模式兼容，不需要迁移。

## 静默入库与回复目标

- 黑名单模式会接收该账号下全部私聊：名单外 QQ 正常触发回复，名单内 QQ 的消息仍会写入对应渠道聊天记录，只是不触发模型、不回复。
- 私聊回复会自动发给当前消息发送者，不再固定使用渠道最初配置的目标。
- 渠道详情页在发现会话中可直接把 QQ「加入黑名单」；白名单模式仍是「设为本渠道目标」。

## 扩展接口

- 渠道元数据新增 `targetMode` / `targetIds`，用于描述私聊名单模式与多个目标。
- `napcat-channel` 服务的 `targetOf(channel)` 返回增加 `mode` 与 `ids` 字段。
- `napcat:trigger-decision` 拦截事件支持 `write=true`，便于扩展实现“只静默入库、不回复”。

# 念风Chat v2.2.1-preview.2

本版延续 v2.2.1 的预览线，主要加入插件搜索与外部插件兼容性修正。

## 插件管理

- 插件页工具栏新增搜索框，可按插件名称、ID、版本、描述、开发者 / 作者快速过滤当前插件列表。
- 搜索期间保留按状态 / 名称 / 问题数排序；没有匹配项时显示空状态提示。

## 外部插件兼容性

- 移除 v2.0.2 引入的“外部插件主版本必须与内核主版本一致”规则。
- 插件版本号不再影响能否加载；1.x 等旧版本号的外部插件如果实际依赖正常，会照常激活。
- 需要限制内核版本时，可在插件模块或 `manifest.json` 中显式声明 `minAppVersion` / `maxAppVersion`；
  只有声明范围不满足时才标记为「内核不兼容」并阻止激活。

## 其他

- 更新版本号到 `2.2.1-preview.2`。

# 念风Chat v2.2.0-preview.6

本次预览主要增加本体版本选择、在线更新与一键重启，并同步整理内部插件版本号。

## 本体版本更新与重启

- 侧栏「欢迎」页新增「版本与更新」区域，可直接查看当前版本和运行方式。
- 更新源默认使用国内 GitHub 镜像源，也可以手动切换到 GitHub 官方源。
- 自动读取官方仓库的 Release 列表，可选择任意平台适配版本进行更新或降级。
- 更新时会自动识别当前运行方式：
  - Web 部署版更新 Web 部署包；
  - Web 源码运行方式更新源码包；
  - Windows 桌面版更新 EXE。
- 更新过程会完全关闭当前项目，再下载、解压并替换对应文件；数据目录、用户配置、会话记录和外部插件不受影响。
- Web 版更新完成后会以双击启动脚本的方式重新运行，并保留可见终端窗口；EXE 版更新完成后自动启动新版本。
- 新增「重启念风」按钮：完全关闭当前项目后自动重新运行，Web 版同样保持可见终端窗口。

## 更新期间的浏览器加载动画

- 更新或重启期间，浏览器会显示简洁的转圈加载动画，不展示进度条。
- 新版本重新运行后，浏览器会自动刷新并加载实际界面，加载动画自然消失。
- 页面刷新或重新打开也会识别维护状态，避免在后端尚未就绪时进入半加载界面。

## 版本与插件

- 项目版本、运行时版本、桌面壳版本、关于页版本统一升级到 `2.2.0-preview.6`。
- 本轮有改动的内置插件同步递增版本：
  - `backend-client` 1.1.0
  - `plugin-manager` 1.1.0
  - `modal-host` 1.1.0
  - `market-view` 1.1.0
  - `settings-item-plugins` 3.2.0
  - `welcome-view` 1.1.0

## 兼容性与升级说明

- 更新前请保持当前浏览器页面打开；Web 版会在新后端就绪后自动刷新。
- EXE 版更新期间窗口会完全关闭，更新完成后自动启动新版本。
- 更新只替换程序本体文件，不会删除 `user_data`、`data`、外部插件目录或本机配置。
- 更新源不可用时可在「欢迎」页切换到 GitHub 官方源后重试。

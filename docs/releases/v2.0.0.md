# 念风 Chat v2.0.0

本次是架构级更新：后端终端成为业务本体，WebUI 专注视觉与操作界面；消息、工具、上下文、记忆等核心执行统一由后端常驻代聊完成。

## 架构

- 插件新增运行范围：`server` / `webui` / `both`。
- 浏览器 WebUI 不再加载 `chat-flow`、`context-builder`、`chat-tools`、`memory-store`、`model-service`、`tool-registry`、`document-service`、`chat-queue` 等业务执行插件。
- 后端终端默认启动服务端常驻代聊；关闭 WebUI 后，QQ、NapCat、微信等渠道消息继续处理。
- WebUI 通过 `agent-client` 与 `/api/agent/send`、`/api/agent/status`、`/api/agent/cancel` 把发送、状态与停止生成交给后端终端。
- 浏览器只加载视觉、设置、数据缓存与渠道管理插件；界面仍保持完整可用。

## 插件与加载

- 插件模块并发加载，禁用 / 未安装的插件不再被导入。
- 插件清单本地缓存，后台增量同步；带版本号的外部插件模块使用强缓存，普通源码使用 ETag 304 与 gzip。
- 插件启用 / 更新 / 删除支持运行期热同步；更新外部插件会重新导入新模块。
- 外部插件 bridge 重新加载时替换同一路由的处理函数，修复重扫后旧实例继续处理请求的问题。

## 上下文与聊天

- 人设提示放到 system prompt 更靠后的位置，降低长群聊中的稀释。
- 每条用户消息标注来源与作用域，明确当前请求与历史背景的区别。
- 跨渠道工作记忆默认限流为最近 2 轮，可通过 `chat.crossChannelMemoryRounds` 调整或关闭。
- 群聊明确只回复当前请求消息，减少旧话题被当成当前事件的情况。

## 渠道与工具

- NapCat、QQ 官方机器人、微信 Clawbot 继续使用后端 bridge 承担真实收发；WebUI 渠道插件负责管理界面。
- 独立扩展升级到 2.0.0，适配新的运行范围与路由生命周期：GitHub 助手、群聊工具、知识库、点歌台、群管助手、邮箱、联网访问。
- 知识库修复重新扫描后写入提示“database is not open”的问题。
- 日志按 clientId 去重，HTTP 访问噪音默认隐藏。

## 升级说明

- 项目版本提升到 v2.0.0；独立扩展统一为 v2.0.0。
- 升级后需要重启一次后端，之后插件安装 / 更新 / 卸载无需重启。
- 请保持后端常驻代聊为开启状态；如果使用 `--no-agent`，WebUI 只能查看和配置，不能发送消息。
- 旧版外部插件建议升级到 v2.0.0；未声明运行范围的插件默认按 `both` 加载。

## 测试

- `npm test` 全量通过：模块、依赖、后端、安全、图片、渠道、前端冒烟、对话、工具链路与厂商协议。
- 新增 `npm run test:webui-scope`（22 项）与 `npm run test:agent-bridge`（6 项），覆盖 WebUI 职责拆分与后端终端代聊全链路。

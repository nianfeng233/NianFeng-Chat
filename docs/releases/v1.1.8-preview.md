# 念风 Chat v1.1.8 Preview 1

> 这是 preview 分支的预发布快照，用于提前验证 v1.1.8 的更新；正式发布请以 `v1.1.8`（main）为准。
> 本预览版与 v1.1.8 使用同一份源码构建，更新内容详见 `docs/releases/v1.1.8.md`。

## 本版重点

- 服务端常驻代聊（server-agent）：WebUI 关闭后渠道消息仍可处理。
- NapCat 合并转发、CQ 码白名单、心跳看门狗与积压不自动回复。
- 外部插件上传安装与 bridge 热加载。
- 严格工具模式、文本工具协议降级与 `chat_send` 兜底。
- 图片最近 2 张 / 8MB 预算、转发深读、引用图片注入。
- 模型页临时候选、远端模型发现、DeepSeek reasoning 降级。
- Host / Origin / SSRF / 插件 zip 安全加固。
- `backend-client` 健康检查防抖，修复 WebUI 间歇性失联。

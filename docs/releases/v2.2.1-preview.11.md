# 念风Chat v2.2.1-preview.11

本版修复模型在同一轮里重复发送相似内容的问题，并优化运行日志页在日志量较大时的加载体验。

## 聊天回复

- `chat_send` 工具结果现在会明确返回本次实际发送的条数、消息 ID、本轮是否结束以及发送状态提示，模型可以直接确认消息已经发出。
- 模型发完内容但仍未结束本轮时，工具结果会提示：已经没有新内容时，直接用空 `messages` + `end=true` 收尾，不要为了补 `end` 再复述一遍。
- 支持已发送内容后的空 `messages` + `end=true` 纯结束信号，不会产生新消息；本轮尚未发送任何内容时，空结束会被拒绝，避免模型沉默跳过回复。
- system prompt 与工具说明同步强调：发送完最后一批内容必须设置 `end=true`，并且不要重复发送相同或近似内容。

## 运行日志

- 日志页首次进入或手动刷新时，先拉取最新一段日志立即显示，再在后台分页回填更早历史；日志量较大时不需要等待全部历史下载完成。
- 增量轮询继续按响应中的最新日志 ID 追平，代理截断或短时积压时不会漏掉中间日志。
- SSE 实时流与 3 秒轮询兜底保持不变。
